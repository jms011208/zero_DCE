# 지표 평가 정리 (개선 방법별)

> 지금까지 시도한 노이즈 개선 방법을 같은 기준으로 모아 둔 표. 실험 경위와 코드 변경은 [[03 수정사항]], 날짜별 기록은 [[02 진행사항]] 참고.

## 1. 평가 설정
- **평가 데이터**: LOL `eval15` (저조도/정답 쌍 15장, 400x600)
- **기준(base)**: 원본 Zero-DCE (`snapshots/Epoch99.pth`) 결과. 모든 방법은 이 결과에 노이즈 제거를 더한 것
- **스크립트**
  - `eval_lol.py`: 기존 vs CNN의 PSNR/SSIM
  - `compare_denoise.py`: 기존 / CNN / 고정 수식 필터 / 밝기·색 분리를 같은 지표로 한 번에 비교

## 2. 지표 설명

| 지표 | 의미 | 좋은 방향 |
|---|---|---|
| PSNR (dB) | 정답과의 픽셀 차이. 이 데이터에서는 **밝기 차이**(Zero-DCE가 정답보다 어둡게 복원)가 대부분을 좌우해서 노이즈 비교에는 변별력이 거의 없음 | 높을수록 |
| SSIM | 정답과의 국소 구조 유사도. 노이즈 감소에 민감, 특히 **밝기 노이즈**에 민감하고 색 노이즈에는 덜 민감 | 높을수록 |
| 경계 유지율 (`edge_ratio`) | 정답에서 뚜렷한 경계(5x5 평균 후 Sobel > 0.3) 픽셀에서 `출력 기울기 / 기존 Zero-DCE 기울기` | 1에 가까울수록 (작을수록 흐려짐) |
| 밝기 노이즈 (`flat_luma`) | 정답이 평평한 픽셀(Sobel < 0.05)에서 밝기 고주파 성분 표준편차 x1000 | 낮을수록 |
| 색 노이즈 (`flat_chroma`) | 같은 위치의 Cb+Cr 고주파 성분 표준편차 x1000 | 낮을수록 |
| 시간 (s) | 이미지 한 장의 노이즈 제거 단계 시간 (Zero-DCE 제외) | 짧을수록 |

**지표의 한계**
- 경계 유지율은 경계에 섞인 노이즈를 지워도 1보다 작아짐 → 약하게 보정하는 방법에 유리
- 경계 유지율은 뚜렷한 경계만, 노이즈 지표는 평평한 영역만 봄 → **질감(중간 기울기) 보존은 측정 안 됨**. 육안 비교 필요


## 3. 개선 방법 설명
모든 방법은 같은 흐름 위에 있다: **저조도 입력 x → Zero-DCE(곡선 8회 적용) → 밝아진 이미지 E → 노이즈 제거 → 최종 출력**.
밝기를 올리는 곡선 `LE(x) = x + α·x·(1 − x)`가 어두운 픽셀일수록 크게 증폭하므로, 원래 어두웠던 곳의 노이즈도 같이 커진다. 아래 방법들은 모두 E의 노이즈를 줄이는 방법이며, Zero-DCE 자체는 바꾸지 않는다.

### 3-1. 노이즈 억제 CNN (학습 기반, `model_v2.py`)
**구조**
- Zero-DCE 뒤에 작은 CNN(NoiseSuppressor, 파라미터 5,812개, Zero-DCE의 약 7%)을 붙인다
- 입력: E(3채널) + **gain 맵**(1채널, 픽셀별로 얼마나 밝아졌는지 = 7x7 평균 밝기의 비율로 `log(1 + 평균(E)/평균(x)) / log(51)`, 0~1). 많이 밝아진 곳일수록 노이즈도 크게 증폭되므로 노이즈 위치의 단서가 된다
- 3x3 합성곱 3층(16채널, 가운데 층은 dilation 2로 9x9 범위를 봄) 뒤에 출력 머리 2개
  - **노이즈 마스크 M** (1채널, sigmoid, 0~1): 이 픽셀에 노이즈가 많다는 확신도
  - **잔차 R** (3채널, tanh x 0.2): 그 픽셀에서 빼야 할 노이즈 성분
- 최종 출력: `out = E − M · R`. M이 0이면 그 픽셀은 Zero-DCE 결과 그대로, M이 클수록 많이 보정
- 초기값은 "아무것도 안 고치는" 상태(M≈0.12, R≈0)에서 시작

**학습** (`lowlight_train_v2.py`, Zero-DCE는 `Epoch99.pth`로 고정하고 CNN만 학습)
- 정답(깨끗한 이미지)이 없으므로 **합성 노이즈**로 학습 데이터를 만든다
  1. 학습 이미지 x에 센서 노이즈를 더해 x_noisy 생성: 분산 = `a·x + σ_read²` (이미지마다 σ_read 0.005~0.03, a 0~0.01, 20%는 노이즈 없음)
  2. `E_clean = DCE(x)`, `E_noisy = DCE(x_noisy)` → 곡선이 노이즈를 증폭한 결과가 자연스럽게 생김
  3. CNN이 E_noisy로부터 E_clean을 복원하도록 학습
- 손실: `L1(out, E_clean) + 0.1 · MSE(M, 실제 노이즈 크기 맵)`
  - 노이즈 크기 맵 = `|E_noisy − E_clean|`을 5x5 평균 후 15배, 0~1로 자름

**경계 보존 손실** (선택 옵션)
- `--lam_edge k`: 정답에서 경계를 찾아(밝기 3x3 평균 후 Sobel 기울기) 경계 픽셀의 L1 오차에 (1 + k)배 가중치 → 경계를 깎으면 손해가 커짐. `4` 권장
- `--lam_grad k`: 출력과 정답의 밝기 Sobel 기울기 차이(L1)를 손실에 추가 → 실험상 오히려 흐려져 비권장

**특징**: 이미지 내용에 맞춰 보정 강도를 스스로 정할 수 있지만, 학습이 필요하고 합성 노이즈와 실제 노이즈의 차이(도메인 차이)에 영향을 받는다.

### 3-2. 후처리: 보정 강도 `alpha`와 경계 블렌딩 (CNN 결과에 적용, 재학습 없음)
- **보정 강도**: `out = E − α · M · R`. α를 1보다 낮추면 보정이 약해져 경계는 덜 흐려지고 노이즈는 더 남음
- **경계 블렌딩**: E의 밝기를 5x5 평균한 뒤 Sobel 기울기로 경계 맵 w(0~1)를 만들고 `final = w · E + (1 − w) · out`. 경계에서는 보정 전 결과, 평평한 곳에서는 보정 결과를 사용
- 저장소 스크립트에는 없고 Colab 셀로만 시험함

### 3-3. 고정 수식 필터 (학습 없음, `compare_denoise.py`)
정해진 수식으로 E에 직접 적용한다. 학습이 필요 없고 동작을 수식으로 설명할 수 있으며, 같은 입력이면 항상 같은 결과가 나온다.

**비지역 평균 (Non-Local Means, `nlm`)**
- 원리: 각 픽셀 주변의 작은 조각(7x7)과 **모양이 비슷한 조각**을 넓은 범위(21x21)에서 찾아, 비슷할수록 큰 가중치로 평균한다. 노이즈는 무작위라 평균하면 상쇄되고, 같은 구조(경계, 무늬)는 반복되므로 유지된다
- 수식: `out(p) = Σ_q w(p,q) · E(q) / Σ_q w(p,q)`, `w(p,q) = exp(−‖조각(p) − 조각(q)‖² / h²)`
- 설정: `--nlm_h`(밝기 세기), `--nlm_h_color`(색 세기). OpenCV `fastNlMeansDenoisingColored`가 내부에서 밝기(L)와 색(a, b)을 따로 처리하므로 두 세기를 따로 정할 수 있음 (0~255 기준)

**양방향 필터 (Bilateral, `bilateral`)**
- 원리: 주변 픽셀을 평균하되 **거리가 가깝고 밝기도 비슷한** 픽셀에만 큰 가중치를 준다. 경계 건너편 픽셀은 밝기 차이가 커서 가중치가 작아지므로 경계가 덜 흐려진다
- 수식: `w(p,q) = exp(−|p − q|² / 2σs²) · exp(−|E(p) − E(q)|² / 2σc²)`
- 설정: `--bil_d`(이웃 지름), `--bil_sigma_space`(σs, 거리), `--bil_sigma_color`(σc, 밝기 차이 허용. 작을수록 경계를 더 지킴)

**가이디드 필터 (Guided, `guided`)**
- 원리: 각 작은 창(반경 r) 안에서 출력이 안내 이미지 I(여기서는 E의 밝기)의 **선형식** `a · I + b`라고 가정하고 a, b를 구한다
  - 창 안의 분산이 eps보다 크면(경계) a ≈ 1 → 원래 값을 유지
  - 분산이 eps보다 작으면(평평한 곳) a ≈ 0 → 창의 평균으로 평활화
- 수식: `a = cov(I, p) / (var(I) + eps)`, `b = mean(p) − a · mean(I)`, 출력 = `mean(a) · I + mean(b)`
- 설정: `--gf_r`(창 반경), `--gf_eps`(평활 기준 분산. 클수록 강하게 평활, 기본 0.004는 너무 강했고 0.001이 나음)
- 박스 필터만 쓰므로 매우 빠름

**BM3D (`bm3d`)**
- 원리: (1) 비슷한 조각들을 찾아 3차원 묶음으로 쌓고(Block Matching), (2) 묶음 전체를 3차원 주파수 변환한 뒤 작은 계수(노이즈)를 0으로 만들고(협업 필터링), (3) 되돌려 원래 위치에 겹쳐 평균한다. 이 과정을 두 번 반복해 정밀도를 높임
- 고전 방식 중 성능이 가장 좋은 편이지만 매우 느림 (이미지당 약 40초)
- 설정: `--bm3d_sigma`(노이즈 표준편차, 0이면 이미지에서 자동 추정). `pip install bm3d` 필요

**밝기 기반 세기 조절 (`--adaptive`)**
- 필터 결과 F를 gain 맵 w(0~1로 정규화)로 섞음: `out = (1 − w) · E + w · F` → 많이 밝아진(노이즈가 크게 증폭된) 곳만 강하게 적용
- 이번 비교 실행에서는 사용하지 않음

### 3-4. 밝기/색 분리 (`ycc_nlm`, `ycc_bilateral`, `ycc_guided`, `ycc_bm3d`)
- 원리: 경계 정보는 대부분 **밝기(Y)**에 있고, 저조도에서 눈에 띄는 얼룩은 **색(Cb, Cr)** 노이즈가 많다. 그래서 밝기는 지키고 색만 강하게 지운다
- 방법
  1. E와 필터 결과 F를 각각 YCbCr로 변환 (`Y = 0.299R + 0.587G + 0.114B`, `Cb = 0.564(B − Y)`, `Cr = 0.713(R − Y)`)
  2. 밝기: `Y = (1 − ycc_luma) · Y_E + ycc_luma · Y_F`
  3. 색: Cb, Cr은 F의 값을 그대로 사용
  4. 다시 RGB로 변환
- 설정: `--ycc_luma` (0 = 밝기 완전 유지 → 경계 거의 손실 없음, 1 = 일반 필터와 같음). 0.3 정도면 밝기 노이즈도 일부 줄이면서 CNN과 같은 경계 수준
- 필터 자체의 세기 설정(`--nlm_*`, `--bil_*`, `--gf_*`)은 일반 필터와 공유

### 3-5. 방법별 특징 요약

| 방법 | 종류 | 학습 | 경계 처리 방식 | 속도 | 조절 손잡이 |
|---|---|---|---|---|---|
| 노이즈 억제 CNN | 학습 기반 | 필요 (합성 노이즈) | 마스크 M으로 보정 위치 선택, `--lam_edge`로 경계 가중 | 빠름 (GPU) | 재학습, `alpha` |
| 비지역 평균 | 고정 수식 | 불필요 | 모양이 비슷한 조각끼리만 평균 | 보통 | `h`, `hColor` |
| 양방향 | 고정 수식 | 불필요 | 밝기가 비슷한 이웃끼리만 평균 | 매우 빠름 | `σc`, `σs` |
| 가이디드 | 고정 수식 | 불필요 | 분산이 큰 곳(경계)은 유지 | 매우 빠름 | `r`, `eps` |
| BM3D | 고정 수식 | 불필요 | 비슷한 조각 묶음의 주파수 변환 후 작은 계수 제거 | 매우 느림 | `σ` |
| 밝기/색 분리 | 고정 수식 조합 | 불필요 | 밝기는 유지, 색만 필터 | 사용 필터와 같음 | `ycc_luma` + 필터 설정 |

### 같은 경계 수준(약 0.987)에서 비교
경계를 같은 정도로 지킬 때 노이즈를 얼마나 지우는지 보는 공정 비교.

| 방법 | 경계 유지율 | 밝기 노이즈 | 색 노이즈 | SSIM |
|---|---|---|---|---|
| CNN (`edge4`) | 0.987 | 19.28 | 21.18 | 0.6073 |
| 비지역 평균 (약) | 0.988 | 19.69 | 13.32 | **0.6599** |
| 양방향 (약) | 0.987 | 18.75 | 22.48 | 0.6443 |
| `ycc_nlm` (luma 0.3) | 0.986 | 19.98 | **6.78** | 0.6469 |
| `ycc_bilateral` (luma 0.3) | 0.987 | 20.18 | 12.48 | 0.6528 |

- 밝기 노이즈는 방법과 관계없이 비슷함(18.8~20.2) → 밝기에서의 경계·노이즈 맞바꿈은 방법 간 차이가 작음
- 차이는 **색 노이즈**와 SSIM에서 남. CNN은 같은 경계 수준에서 색 노이즈가 가장 많이 남고 SSIM도 가장 낮음
- 양방향(약)은 노이즈 지표가 CNN과 거의 같은데 SSIM이 +0.037 높음 → 평평한 영역 노이즈로 설명 안 되는 차이 (CNN이 질감 영역을 손상하거나 색·밝기를 약간 바꾼다는 추정, 확인 안 됨)

## 7. 후처리 시험 (재학습 없음, 예비 CNN 가중치, LOL 3장: 179·748·23)

**보정 강도 `alpha`와 경계 블렌딩**
- `alpha`를 1.0 → 0.5로 낮추면 노이즈 지표 22.7 → 23.7 (기존 24.7), SSIM 0.603 → 0.586. 보정 강도 조절기로는 정상 동작
- 경계 유지율은 모든 설정에서 0.996~0.998로 거의 같음 → 예비 가중치가 경계를 거의 건드리지 않아 효과 판단 불가

## 8. 결론
1. **현재 CNN이 더 나은 지점은 없음.** 경계를 우선하면 `ycc_*`(경계 0.993~1.000, 색 노이즈 3.8~12.6), 노이즈 제거를 우선하면 BM3D·비지역 평균·양방향이 더 좋음. 같은 경계 수준에서도 CNN이 색 노이즈가 가장 많이 남고 SSIM이 가장 낮음
2. **색 노이즈는 경계 손실 없이 제거 가능.** `ycc_luma 0`에서 경계 유지율 0.993~1.000
3. **남은 과제는 밝기 노이즈.** 밝기 노이즈를 줄이면 경계도 같이 흐려지고, 이 관계는 방법 간 차이가 작음. SSIM이 높은 방법(0.68~0.69)은 모두 밝기 노이즈를 많이 지운 대신 경계를 조금씩 희생
4. **용도별 후보**

| 목적 | 추천 | 근거 |
|---|---|---|
| 경계 최우선 | `ycc_bilateral` (luma 0) | 경계 1.000, 빠름 |
| 색 얼룩 최소 + 경계 유지 | `ycc_guided` (luma 0) | 색 노이즈 3.84, 경계 0.996 |
| 균형 | `ycc_nlm` 또는 `ycc_bilateral` (luma 0.3) | CNN과 같은 경계 수준에서 SSIM +0.04~0.05, 색 노이즈 1/3~1/2 |
| SSIM 최우선 | BM3D | SSIM 0.6935, 경계 0.980. 단 이미지당 약 40초 |
| 빠르고 SSIM 높음 | 양방향 (기본값) | SSIM 0.6915, 0.03초. 경계 0.959 |
