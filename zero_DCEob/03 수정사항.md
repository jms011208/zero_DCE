## 노이즈 억제망 v2 설계
**구조** (`model_v2.py`)
```
x(저조도) -> [DCE-Net, 기존/고정] -> E(밝아진 이미지) ─┬──────────────────────────┐
                                                        ├-> [NoiseSuppressor] -> M(노이즈 마스크), R(제거할 노이즈)
x, E -> gain 맵(얼마나 밝아졌나) ───────────────────────┘
최종 출력 out = E - M * R
```
- NoiseSuppressor: 3x3 conv 3개(16채널, 가운데는 dilation 2) + 머리 2개(마스크 1채널 sigmoid, 잔차 3채널 tanh x 0.2). 파라미터 5,812개 (DCE-Net 79,416개의 약 7%)
- M이 0이면 그 픽셀은 기존 Zero-DCE 결과 그대로, M이 클수록 많이 보정 → "노이즈가 심하다고 판단한 픽셀만 보정"
- 입력에 gain 맵을 같이 주는 이유: 많이 밝아진(원래 어두웠던) 곳일수록 노이즈도 같이 증폭됨
- 초기값은 "아무것도 안 고치는" 상태(M≈0.12, R≈0)에서 시작

**학습** (`lowlight_train_v2.py`, 2단계 학습: DCE-Net은 `Epoch99.pth`로 고정)
1. 학습 이미지 x에 합성 센서 노이즈를 더해 x_noisy 생성 (분산 = a·x + σ_read², 이미지마다 σ_read 0.005~0.03, a 0~0.01, 20%는 노이즈 없음)
2. `e_clean = DCE(x)`, `e_noisy = DCE(x_noisy)` — 곡선이 노이즈를 같이 증폭한 결과
3. 손실 = `L1(out, e_clean)` + 0.1 · `MSE(M, 실제 노이즈 크기 맵)`
- 노이즈 크기 맵 = |e_noisy − e_clean|을 5x5 평균 후 15배, 0~1로 자름 (`--mask_scale 15`). 측정 결과 DCE-Net을 거치면 입력 노이즈가 약 1.4~2.3배로 커지고, 15배일 때 마스크 정답이 0~1에 고르게 분포함

**알려진 한계**
- 합성 노이즈(가우시안 + 신호 의존)로 학습하므로 실제 센서 노이즈와 차이가 있음 (domain gap)
- DCE-Net을 고정하므로 노이즈를 덜 증폭하는 방향으로는 학습되지 않음 (필요하면 `freeze_dce` 해제 후 공동 학습)
- 저장소의 `lowlight_train_v2.py`에는 검증 세트 분리가 없음

## 예비 결과 (CPU, 매우 작은 학습 — 의미 있는 결론은 Colab 전체 학습 후)
- 체크포인트: 학습 이미지 25장, 64x64 랜덤 크롭 200개, 80 epoch (약 1분). 저장소에는 올리지 않음
- 합성 노이즈 검증(보지 않은 5장의 크롭 40개): L1 0.0355 → 0.0302, PSNR 24.57 → 26.45 dB. 같은 설정으로 크롭 400개, 100 epoch까지 돌린 별도 실행에서는 24.81 → 28.24 dB로 더 좋아져, 학습량을 늘리면 더 개선될 여지가 있음
- LOL `eval15` (실제 저조도 15장, 정답 대비):

| | 기존 Zero-DCE | + 노이즈 억제 | 차이 |
|---|---|---|---|
| PSNR (평균) | 14.861 dB | 15.055 dB | +0.194 |
| SSIM (평균) | 0.5627 | 0.6048 | +0.0421 |

  - PSNR은 15장 중 14장, SSIM은 15장 모두 상승 (PSNR이 내려간 1장: 179.png 20.219 → 19.871)
  - 주의: 이미지 15장, 1회 실행, 매우 작은 학습이므로 확정적인 결과가 아님. 기존 Zero-DCE는 LOL 정답보다 어둡게 복원해서 PSNR 절대값이 낮음(비교는 같은 조건의 차이로만 볼 것)
- 육안: 노이즈 마스크 M은 증폭된 노이즈가 많은 밝아진 벽면 등에서 높게, 매우 어두운 영역에서는 낮게 나옴. 보정 효과는 약하게 보임
